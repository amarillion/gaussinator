How to play

Goal: turn the matrix into reduced row echelon form (RREF):

  • each leading (first non-zero) entry of a row is 1,
  • leading entries form a staircase from top-left to bottom-right,
  • every column with a leading 1 has zeros everywhere else,
  • all-zero rows sit at the bottom.

Legal moves (elementary row operations):

  • Swap two rows,
  • Multiply a row by any non-zero number k,
  • Add k × one row to another row (use k = −1 to subtract).

Keyboard:

  • ↑ ↓ or K J — select row
  • Shift+↑/↓ — move the selected row
  • type e.g. -3/4 — set k
  • M — multiply selected row by k
  • A / S — add / subtract k×row, then pick target with ↑↓ and Enter
  • U undo · H hint · R restart · Esc cancel / reset k

Touch: tap a row to select it, swipe a row up/down to swap it, then use the buttons below the board.
